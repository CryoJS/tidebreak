## ℹ️ About
 
Tidebreak is a physics-driven platformer where players navigate hazards using wall jumps, slides, and ziplines while managing rising water levels. It includes a built-in **map editor**, letting players build, save, and share their own levels alongside the default maps that ship with the game.
 
### Features
 
- Custom tile-based map editor with save/load support
- Player physics: wall jump, slide, water interaction
- Zipline traversal mechanics
- Difficulty-rated maps with best-time tracking
- Built on a custom UI system (Gum) and original data structures (BST, merge sort, undo/redo)
 
## 🚀 Tech Stack
 
- **Engine:** MonoGame (DesktopGL)
- **Language:** C#
- **UI:** Gum
- **Platform:** Windows
